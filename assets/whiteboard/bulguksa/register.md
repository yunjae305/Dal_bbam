# 불국사 쇼츠 — 앱 등록 정보

완성 파일: `public/videos/bulguksa.mp4` → 앱에서의 주소는 **`/videos/bulguksa.mp4`**

## `/admin/shorts` 입력값

| 항목 | 값 |
|---|---|
| 연결 문화재 | 불국사 (로컬 데모 데이터 기준 `contentId` = `bulguksa`) |
| 제목 | 불국사, 천 년을 견딘 돌 |
| 소개 | 신라 재상 김대성이 세운 절은 임진왜란에 타 없어졌지만, 석축 기단과 두 탑은 자리를 지켰습니다. |
| 영상 주소 | `/videos/bulguksa.mp4` |
| 영상 언어 | 한국어 |
| 길이 | 60초 |
| 태그 | `문화재 소개`, `세계유산`, `불교문화` |
| 대표 이미지 | 선택 사항. 비우면 영상 첫 프레임 대신 기존 장소 이미지를 쓴다 |
| 대본 | 선택 사항. 필요하면 [`bulguksa.srt`](bulguksa.srt) 내용을 넣는다 |

나레이션이 영상 안에 들어 있으므로 **별도 음성 파일은 등록하지 않는다.** 쇼츠 재생기는
음소거로 시작하고 사용자가 소리 버튼으로 켠다.

## 사양

- 1080×1920 세로(9:16), 60fps, 60.00초
- H.264 + AAC 48kHz 모노, 약 13MB
- 화면 안에 글자 없음 — 자막을 태우지 않았고 펜대의 제작자 문구도 지웠다

## 등록 전에 확인할 것

1. **운영 DB의 실제 `contentId`.** 위 `bulguksa`는 로컬 데모 데이터 값이다. 운영 환경에서는
   TourAPI가 부여한 실제 contentId를 확인해 연결해야 한다.
2. **관리자 계정.** `ADMIN_EMAILS`가 비어 있으면 `/admin/shorts`에 들어갈 수 없다.
3. **쇼츠 스키마.** 원격 DB에 `shorts.video_url` 등 누락 컬럼이 있어
   [DB 작업 안내](../../../docs/database-operations-2026-09-06.md)의 마이그레이션이 먼저 필요하다.

셋 다 환경 설정 문제이고 영상 자체와는 무관하다. 파일은 지금 상태로 등록 가능하다.

## 저장소 용량

`public/videos/bulguksa.mp4`(13MB)는 앱 배포에 포함돼야 하므로 커밋한다.
`scene-*-whiteboard.mp4`(각 4.4MB)는 중간 산출물이고 원본 PNG와 주석으로 언제든 다시 만들 수 있으니
커밋하지 않는 편이 낫다. `voice-samples/`도 음성을 InJoon으로 확정한 뒤에는 지워도 된다.
