# TourAPI 다국어·스토리텔링 데이터 인수인계 (2026-09-20)

관광지 이름과 해설이 외국어로 보이지 않는 이유는 코드가 아니라 **API 권한**이다. 현재 `TOUR_API_KEY`는
국문 서비스(KorService2)에만 등록돼 있어 영문·일문·중문 서비스는 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(403)를
돌려준다. 아래 네 가지를 활용신청한 뒤, 이 문서의 프롬프트를 AI에게 그대로 주면 된다.

## 활용신청할 데이터

| 데이터 | 서비스명 | 링크 |
|---|---|---|
| 한국관광공사_영문 관광정보서비스_GW | `EngService2` | https://www.data.go.kr/data/15101753/openapi.do |
| 한국관광공사_일문 관광정보서비스_GW | `JpnService2` | https://www.data.go.kr/data/15101760/openapi.do |
| 한국관광공사_중문 간체 관광정보서비스_GW | `ChsService2` | https://www.data.go.kr/data/15101764/openapi.do |
| 한국관광공사_관광 스토리텔링 DB | 파일(CSV) + 오픈API | https://www.data.go.kr/data/3041768/fileData.do |

**중요:** 공공데이터포털은 계정당 인증키가 하나다. **기존 `TOUR_API_KEY`를 발급받은 계정과 같은 계정으로
신청하면 키를 바꿀 필요가 없다.** 다른 계정으로 신청했다면 새 키로 교체해야 한다(아래 프롬프트에 분기 있음).

Node.js와 npm이 설치돼 있습니다. 목표는 관광지 이름을 영어·일본어·중국어로 채우는 것입니다.

## 스토리텔링 DB (선택, 2단계 작업)

`한국관광공사_관광 스토리텔링 DB`는 스마트투어가이드 오디오 해설 대본 1,624건이다(한국어 609 · 영어 564 ·
일본어 417 · 중국어 34). 라이선스 제한이 없고 로그인 없이 CSV로 받을 수 있다. 인코딩은 CP949다.

**먼저 알아야 할 제약**

- 스팟아이디가 언어별로 다르다. 1,444개 아이디 중 두 개 언어를 함께 가진 아이디는 **0개**다.
  같은 장소의 한국어·영어·일본어 대본을 묶으려면 이름을 보고 사람이 짝지어야 한다.
- 스팟 단위가 전시물·지점("관모, 관꾸미개", "계림 앞에서")이라 관광지 545곳과 1:1이 아니다.
  **이름 유사도로 자동 매칭하면 엉뚱한 해설이 붙는다. 하지 말 것.**
- 중국어는 전체 34건뿐이라 이 데이터로 채울 수 없다.

**경주 주요 관광지 확보량** (한국어 / 영어 / 일본어)

석굴암 4/4/4 · 김유신묘 6/4/6 · 대릉원·천마총 4/3/7 · 동궁과 월지 9/1/8 · 양동마을 2/2/2 ·
계림 3/3/0 · 첨성대 4/0/3 · 불국사 3/0/0 · 월정교 0/0/0 · 국립경주박물관 0/0/0

**권장 진행 방식:** 자동 적재 대신 위 주요 관광지 20~30곳만 `스팟아이디 → contentId + 언어` 매핑표를
손으로 만들어 `place_translations.overview`에 넣는다. 화면에는 출처(한국관광공사 스마트투어가이드)를
표기한다. 이 작업은 앱 담당이 진행하며, 팀원은 1~4단계(이름 채우기)까지만 하면 된다.
