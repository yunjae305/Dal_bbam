# 문화재 쇼츠 등록과 운영

2026-09-06 사용자 결정: 초기 쇼츠는 미리 제작한 **문화재가 인격화되어 자신을 소개하는 영상**과 **짧은 문화재 소개 영상**을 등록해 제공한다. AI로 제작한 완성 영상도 같은 방식으로 등록한다. 영상 재생은 AI 추천 서비스와 독립적으로 동작한다.

## 현재 상태 (2026-09-19)

사용자 결정으로 **영상 피드는 감춰 두었다.** 사용자 화면(`/shorts`)에는 "쇼츠 영상은 추후 추가 예정입니다."
안내가 4개 언어로 표시되고, 같은 화면의 방문자 스토리는 그대로 동작한다. 아래 등록 절차와 관리자 화면,
저장된 영상 데이터는 손대지 않았다.

영상을 준비한 뒤 켜는 순서: `/admin/shorts`에서 등록·공개 → 환경변수 `FEATURE_SHORTS=true` → 재배포.
이 변수를 넣지 않으면 출시 점검(`release:check`)도 게시된 영상을 요구하지 않는다.

## 등록 순서

1. 관리자 계정으로 `/admin/shorts`에 접속한다. 관리자 이메일은 서버의 `ADMIN_EMAILS`에 설정한다.
2. 연결할 문화재, 영상 제목·소개, 영상 언어, 길이와 태그를 입력한다. `문화재 캐릭터`, `문화재 소개` 같은 태그로 콘텐츠를 구분할 수 있다.
3. MP4 주소 또는 YouTube 영상/Shorts 링크를 입력한다. 대표 이미지와 대본은 선택 사항이다.
4. 미리보기로 확인하고 초안으로 저장한다. 목록에서 수정·공개·비공개 전환을 할 수 있다.
5. 공개한 영상은 `/shorts`에서 재생된다. 장소 정보 링크로 해당 문화재 상세 화면에 이동한다.

## 영상 준비

| 입력 방식 | 준비 방법 |
|---|---|
| 앱에 포함한 MP4 | 파일을 `public/videos/`에 두고 `/videos/cheomseongdae-intro.mp4` 같은 주소를 입력한다. 파일 추가는 앱 배포에 포함한다. |
| 외부에 저장한 MP4 | 브라우저가 직접 재생할 수 있는 HTTPS MP4 주소를 입력한다. 로그인 페이지나 일시적인 로컬 `blob:` 주소는 사용할 수 없다. |
| YouTube 영상 | 일반 영상·Shorts 링크 또는 영상 ID를 입력한다. 해당 영상의 외부 재생이 허용돼 있어야 한다. |

관리 화면은 영상 주소와 게시 정보를 저장한다. 파일 전송·영상 제작 기능은 포함하지 않는다. 9:16 세로 영상을 권장하며 재생기는 MP4와 YouTube를 지원한다. 재생 카드는 화면 높이에 맞춰 조정하고, 작은 화면에서도 하단 버튼까지 스크롤할 수 있다. 영상 길이 입력은 1~600초, 태그는 최대 6개다. 영상 언어는 실제 음성·자막에 맞춰 지정하며, UI 언어 변경이 완성 영상의 음성이나 자막을 자동으로 번역하지는 않는다.

영상은 처음에 음소거로 재생되며 사용자가 소리를 켤 수 있다. 화면에서 벗어난 영상은 정지한다. 완성 영상에 별도 음성 파일이 등록되지 않았다면 AI 해설 생성 버튼을 표시하지 않는다. 별도 음성 파일이 있는 기존 콘텐츠와 이미지·해설 콘텐츠는 계속 지원한다.

## 데이터와 권한

관리자 목록은 초안과 공개 영상을 모두 보여 주고, 일반 피드는 공개 영상만 가져온다. 관리자 API는 서버에서 세션 또는 관리자 비밀키를 검증하고 개인 응답을 캐시하지 않는다. 화면에 입력한 공개 상태는 서버 저장 성공 후에만 목록에 반영한다.

원격 DB에는 `shorts.video_url`·`youtube_video_id` 등 누락 스키마가 있어 [DB 작업 안내](database-operations-2026-09-06.md)의 적용이 먼저 필요하다. 현재 로컬 운영 설정의 `ADMIN_EMAILS`도 비어 있으므로 운영할 관리자 계정 이메일을 지정해야 한다. 이번 쇼츠 보완은 새 DB 마이그레이션이나 저장소 버킷을 추가하지 않는다. 실제 문화재 영상은 아직 제공·등록되지 않았으며, 테스트용 짧은 패턴 영상은 서비스 콘텐츠가 아니다.

## 검증 범위

2026-09-06 단위·컴포넌트·API 테스트 68개 파일·385개 통과, 타입 검사와 격리 프로덕션 빌드 통과, lint 오류 0개·경고 29개를 확인했다. 관리자 권한, 영상 원고 생략, 초안/공개 전환과 실패 시 상태 보존, 기존 이미지·음성 콘텐츠 편집, 목록 갱신 후 페이지 누락 방지를 포함한다. 별도 음성이 없는 완성 영상 재생에서 AI 해설 요청이 발생하지 않는 것도 확인했다.

전체 브라우저 테스트는 55개 통과·실패 0개·제외 1개다. 직접 만든 320×180 MP4의 실제 재생·정지·음소거·저장·태그 선택·장소 이동은 Chromium 모바일/데스크톱과 Firefox 데스크톱에서 통과했다. Windows WebKit은 운영체제 디코더가 지원되지 않아 실제 재생 한 건만 제외했다. 관리자 기능과 영상 오류 대체 화면은 WebKit을 포함한 네 설정에서 통과했다. Safari 실제 단말 재생은 아직 확인하지 않았다.

관리자 브라우저 검증의 저장 API는 격리된 fixture다. 실제 원격 DB 저장이나 문화재 원본 영상 게시를 검증한 결과로 해석하지 않는다. YouTube는 URL 정규화·미리보기 임베드·재생 제어 메시지를 자동 테스트하며, 실제 제공할 영상의 공개 범위·임베드 허용 여부와 음성·자막은 원본을 등록할 때 확인해야 한다.
