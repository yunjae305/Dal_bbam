# 커뮤니티 화면 명세

## 공통

- 모바일 세로 화면을 우선한다.
- 화면 제목과 주요 행동은 첫 화면에서 인지할 수 있어야 한다.
- 아이콘 단독 버튼은 `aria-label`을 제공한다.
- 포커스 순서는 시각적 순서와 일치한다.
- 날짜·별점·카테고리 이름은 현재 언어 설정에 맞춘다.

## 목록 화면

### 기본 요소

- 제목: `여행자 커뮤니티`
- 보조 문구: `경주 여행의 순간과 꿀팁을 나눠보세요`
- 검색 placeholder: `후기, 장소, 여행 팁 검색`
- 카테고리: 전체, 후기, 꿀팁, 맛집, 숙소
- 지역: 전체 지역 또는 관광지 선택
- 정렬: MVP에서는 최신순 고정
- 카드 클릭: 상세 이동
- 북마크: 카드에서 즉시 저장·해제

### 카드 내용

- 대표 사진 0~1장
- 카테고리 badge
- 연관 장소
- 작성자와 작성일
- 제목과 2~3줄 요약
- 별점: 후기·맛집·숙소만
- 북마크 상태

## 작성 화면

### 검증

- 카테고리 필수
- 장소·지역 정책은 팀 합의 후 필수 여부 결정
- 제목: 공백 제외 1~120자
- 본문: 공백 제외 1~5000자
- 별점: 후기·맛집·숙소에서 1~5 정수
- 사진: JPEG/PNG/WebP, 장당 10MB 이하
- 게시 버튼: 필수 입력과 업로드가 완료되기 전 비활성화

### 닫기

- 수정된 값이 없으면 즉시 닫는다.
- 입력 또는 승인된 미디어가 있으면 폐기 확인을 표시한다.

## 상세 화면

- 존재하지 않거나 비공개인 게시글: 404 상태
- 공개 글은 비로그인도 열람 가능
- 북마크는 로그인 필요
- 작성자에게만 수정·삭제 메뉴 노출
- 본문 줄바꿈 유지
- 사진이 여러 장이면 현재 위치를 알 수 있는 갤러리 제공
- 댓글·좋아요 영역은 이번 범위에서 생성하지 않음

## 반응형

- 390px: 한 열, 화면 전체 너비
- 430px: 같은 정보 구조, 좌우 여백 확장
- 700px 이상: 콘텐츠 최대 폭 700px 중앙 정렬
- 가로 필터는 줄바꿈보다 수평 스크롤을 우선

## 다국어

- 화면 구조가 한국어 길이에만 맞춰지지 않도록 한다.
- 버튼과 chip은 영문·일문 확장 길이를 허용한다.
- 사용자 작성 콘텐츠는 자동 번역하지 않는다.
- 시스템 문구만 `ko/en/ja/zh` 사전에서 제공한다.
